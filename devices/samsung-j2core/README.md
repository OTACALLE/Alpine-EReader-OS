# Samsung Galaxy J2 Core (SM-J260M)

Status: **YELLOW / experimental candidate**, not boot-tested. The tier reflects
that this is the pilot under investigation, not working support.

No kernel, device tree, firmware blob, boot image, or flashing command is
included because none has been verified against a physical device. Before image
work can continue: verify OEM-unlock availability and Download Mode behavior on
the exact unit; identify lawful kernel-source provenance; then establish a UART
or visible kernel-console boot before attempting display integration.
